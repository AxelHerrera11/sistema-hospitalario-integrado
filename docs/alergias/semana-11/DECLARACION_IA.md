# Declaración de uso de inteligencia artificial

**Herramienta:** Claude Code (Anthropic) con el modelo Claude Opus 5.5. **Propósito:** construir el prototipo navegable (HTML, CSS y JavaScript sin dependencias) a partir de los wireframes de la Semana 8, las mejoras de la Semana 9 y los breakpoints de la Semana 10, y recorrerlo con Chrome headless para obtener la evidencia y las capturas.

**Contenido aceptado o modificado:** todos los datos son ficticios y el prototipo no llama a ningún servidor; las respuestas se simulan con los códigos reales del contrato.
