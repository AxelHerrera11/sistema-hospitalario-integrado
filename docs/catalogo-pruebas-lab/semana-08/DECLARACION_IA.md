# Declaración de uso de inteligencia artificial

**Herramienta:** Claude Code (Anthropic) con el modelo Claude Opus 5.5. **Propósito:** diseñar el flujo UX por rol, los wireframes de baja fidelidad, los estados de cada pantalla y las reglas de interacción a partir de los casos de uso, los RF/RNF y el contrato API de las semanas anteriores.

**Contenido aceptado o modificado:** los mensajes de error usan los códigos reales del contrato (`problem+json`); los datos de los wireframes son ficticios.
