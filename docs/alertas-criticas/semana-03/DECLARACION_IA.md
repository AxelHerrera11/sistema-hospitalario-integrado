# Declaración de uso de inteligencia artificial

**Herramienta:** Claude Code (Anthropic) con el modelo Claude Opus 5.5.

**Propósito:** condensar la Semana 3 del PR #54 a un solo flujo dentro del límite de 400 líneas: capas, reglas de dominio, idempotencia, adaptador PDO, pruebas y vista de componentes. Las reglas vienen de las Semanas 1 y 2. Las pruebas se ejecutaron con PHP 8.4 y su salida se copió sin cambios. El 2026-10-21, tras la revisión del PR, la auditoría se alineó con el contrato H8 (migración 000700, PR #582) y la escritura se comprobó contra el esquema HOSPITAL real en PostgreSQL.

**Validación humana:** esta versión condensa la entrega del PR #54, cuya validación humana quedó registrada el 2026-10-13. Axel Eliú Herrera Sánchez es responsable de esta entrega.
