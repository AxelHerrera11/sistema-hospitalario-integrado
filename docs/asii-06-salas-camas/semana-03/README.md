# Micro-HIS Salas y camas — Semana 3

Catálogo independiente en PHP 8.2+ vanilla para crear wards y camas con validación del estado operativo. Utiliza `wards` y `beds` del esquema existente; no agrega tablas.

Ejecutar pruebas: `php micro-his/salas-camas/tests/run.php`.

Ver capas y dependencias en [arquitectura-c4.md](./arquitectura-c4.md).
