# Declaración de uso de inteligencia artificial - Semana 3

**Herramienta:** Claude Code con el modelo Claude Opus 5.5 (`claude-opus-5-5`).

**Propósito:** inspeccionar la organización de los micro-HIS existentes (`ocupacion-hospitalaria`, `rbac`) para seguir sus convenciones; escribir el código PHP de las cuatro capas, el adaptador PDO, el CLI, las pruebas y las vistas C4-PlantUML; y ejecutar las pruebas, los controles por mutación y las validaciones registradas en [EVIDENCIA.md](./EVIDENCIA.md).

**Antecedente reutilizado:** el micro-monolito personal previo de la estudiante (`ASII-Tareas-Yamilet1235`, en PDF) aportó la separación en cuatro capas y el uso de PDO con SQLite. Se ajustaron identidad (código y no nombre), campos y vigencia a Semana 1 y Semana 2 de este repositorio, y se aplicaron los contratos ISP de Semana 2.

**Contenido generado o modificado:** todo el código y la documentación de Semana 3 son borradores generados con IA. Durante el trabajo se corrigieron una aserción de prueba que dependía del orden de claves y una condición sin sentido, y se dividió la entrega en cinco PR para respetar el máximo de 400 líneas.

**Validación:** todas las salidas de EVIDENCIA.md provienen de ejecuciones reales. La revisión humana de la estudiante queda **pendiente** y no se declara realizada.
