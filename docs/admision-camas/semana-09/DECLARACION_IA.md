# Declaración de uso de inteligencia artificial

**Herramienta:** Claude Code (Anthropic) con el modelo Claude Opus 5.5. **Propósito:** aplicar las 10 heurísticas de Nielsen y una inspección WCAG 2.1 AA a los wireframes de la Semana 8, clasificar los hallazgos por severidad y proponer mejoras priorizadas.

**Contenido aceptado o modificado:** la evaluación es una inspección experta sobre wireframes; no reemplaza una prueba con usuarios reales, que se propone para el prototipo de la Semana 11.
