# Micro-HIS Pacientes — Semana 3

Micro-HIS independiente en PHP 8.2+ vanilla para registrar, buscar por código y actualizar pacientes. No usa framework ni Composer propio.

Prueba local: `php micro-his/pacientes/tests/run.php`.

La vista de componentes y sus dependencias está en [arquitectura-c4.md](./arquitectura-c4.md).
