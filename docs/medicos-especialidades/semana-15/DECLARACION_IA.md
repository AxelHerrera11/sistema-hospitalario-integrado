# Declaración de uso de inteligencia artificial

**Herramienta:** Claude Code con el modelo Claude Sonnet 5.5 (`claude-sonnet-5-5`).

**Uso:** apoyo para diseñar los casos de prueba unitarios, de caja blanca y de caja negra, para escribir el script `evidencia/pruebas.php` y para redactar la matriz RF/RNF → prueba y el registro de defectos.

**Revisado y ajustado:** los resultados salen de ejecutar el script contra el código real del módulo (`evidencia/resultado.txt`), no de una suposición; los casos con defecto conocido se informan como tales y no se corrigieron. No se modificó ningún archivo del módulo. La cobertura de ramas se calculó por análisis del código, no con un instrumento.

**Validación humana:** realizada el 2026-10-20. Josué Fernando Hicho García revisó esta entrega y la aprueba.
