# Declaración de uso de inteligencia artificial

## Herramienta y propósito

Se utilizó GitHub Copilot en VS Code para estructurar una propuesta de material
de evaluación: guion de defensa, caso sintético y criterios de revisión. El
material no representa una evaluación ya realizada.

## Instrucciones relevantes

- Preparar material de apoyo para la semana 6 sin inventar resultados.
- Conservar las decisiones de alergias, el rechazo sin persistencia y el
  estado pendiente de `excepcion_alergia`.
- Marcar como `PROPUESTO` o pendiente aquello que no tenga evidencia.

## Uso y cambios humanos

Se aceptó el apoyo de estructura y redacción. Se revisó el caso para que sea
sintético, no contenga datos clínicos reales y no ofrezca consejo médico. Se
retiraron calificaciones, porcentajes, resultados de pruebas y afirmaciones
de evaluación no verificadas.

## Validación humana

La persona usuaria confirmó las restricciones del contenido y que no deben
inventarse métricas ni resultados. No se ha realizado la evaluación descrita;
la aprobación final del paquete y de esta declaración queda pendiente.
