# Declaración de uso de inteligencia artificial

**Herramienta:** Claude Code (Anthropic), modelo Claude Opus 5.5.

**Uso:** apoyo para construir el prototipo navegable en un solo HTML, el mapa de navegación y las capturas desktop y móvil.

**Revisado y ajustado:** el prototipo sigue los roles, estados y mensajes de las Semanas 8 a 10 y los códigos del contrato de la Semana 5. Las capturas se tomaron con el viewport real de cada ancho; contraste y zoom quedan pendientes de medir.

**Validación humana:** realizada el 2026-10-19. Josué Fernando Hicho García revisó esta entrega y la aprueba.
