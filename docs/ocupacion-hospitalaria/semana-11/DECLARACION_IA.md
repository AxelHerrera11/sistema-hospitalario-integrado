# Declaración de uso de inteligencia artificial

**Herramienta:** OpenCode con el modelo GPT-5.6 Sol.

**Propósito:** revisar la consigna de Semana 11 y construir un prototipo navegable HTML/CSS/JS que aplique los flujos, hallazgos y reglas responsive anteriores.

**Prompt relevante:** «hace hasta la semana 14».

**Contenido aceptado o modificado:** el prototipo usa datos ficticios y simulaciones locales; no se presenta como frontend Vue, consumo real de API, autorización de servidor ni prueba formal de conformidad WCAG.
