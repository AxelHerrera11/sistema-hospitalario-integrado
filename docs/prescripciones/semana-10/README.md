# Semana 10 — Diseño para movilidad

Estado: `PROPUESTO`. Este paquete adapta los flujos documentados para una
pantalla estrecha; no modifica la aplicación ni afirma que exista una versión
móvil implementada.

## Entregables

- [Principios y restricciones móviles](principios.md)
- [Flujo móvil propuesto](flujo-movil.md)
- [Wireframe estrecho](wireframe-movil.md)
- [Verificación pendiente](verificacion.md)

## Límites

El flujo conserva la identidad del paciente, los mensajes clínicos y el
rechazo sin persistencia. No define unidades/campos de dosis, no agrega una
excepción de alergia y no asume soporte offline. Pruebas en dispositivos
reales quedan `PENDIENTE`.
