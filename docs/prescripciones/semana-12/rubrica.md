# Rúbrica cualitativa — `PROPUESTO`

| Dimensión | Evidencia esperada | Estado |
|---|---|---|
| Reglas clínicas | Distingue `mild`, `moderate`/`unknown` y `severe`/`life_threatening` | Criterio propuesto |
| No persistencia | Explica que todo rechazo 422 termina sin guardado | Criterio propuesto |
| Arquitectura | Identifica límites y dependencias sin atribuir integración no verificada | Criterio propuesto |
| Accesibilidad | Describe mensajes, teclado y asociación de errores como verificaciones pendientes cuando corresponda | Criterio propuesto |
| Evidencia | Distingue prueba ejecutada de propuesta o plan | Criterio propuesto |

No hay ponderaciones, puntajes, aprobados ni resultados registrados. La
rúbrica requiere revisión humana antes de utilizarse en una evaluación.
