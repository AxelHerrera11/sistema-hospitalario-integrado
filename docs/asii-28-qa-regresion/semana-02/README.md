# ASII-28 — QA funcional y regresión

## Semana 2: diseño y principio SOLID

**Principio aplicado:** LSP (*Liskov Substitution Principle*).

**Flujo:** diseño de casos manuales, campañas de regresión, ejecución, evidencia, defectos y trazabilidad.

Este entregable define requisitos y criterios comprobables y presenta una propuesta conceptual para aplicar LSP. Los nombres de roles de diseño son conceptos explicativos; no representan clases, servicios ni funcionalidades de producción existentes.

## Alcance

Se cubre la preparación de casos manuales, su asociación a campañas, el registro de ejecuciones y evidencias, el resultado aprobado o fallido, la gestión de defectos y las relaciones de trazabilidad entre estos elementos.

La propuesta no prescribe una base de datos, API, formato de evidencia, tecnología de almacenamiento ni reglas de autorización que no estén definidas en el repositorio.
