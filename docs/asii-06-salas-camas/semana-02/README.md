# ASII-06 — Catálogo de salas, wards y camas

## Semana 2: diseño y principio SOLID

**Principio aplicado:** SRP (*Single Responsibility Principle*).

**Flujo analizado:** creación de sala y cama con control de estado operativo.

Esta entrega define requisitos funcionales y no funcionales, criterios de aceptación, un diseño conceptual antes y después de aplicar SRP, y la evidencia disponible en el esquema del repositorio. El diseño posterior es una propuesta; no representa componentes ya implementados.

## Alcance

El análisis se limita a crear wards, crear camas asociadas a un ward y mantener el estado operativo mediante los valores definidos por el esquema. No especifica rutas HTTP, permisos, flujos de admisión ni operaciones adicionales no necesarias para este objetivo.
