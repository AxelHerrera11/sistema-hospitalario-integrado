# Declaración de uso de inteligencia artificial

**Herramienta:** OpenCode con el modelo GPT-5.6 Sol.

**Propósito:** revisar la consigna y ejemplos de Semana 5, evolucionar el Micro-HIS a un prototipo cliente-servidor, redactar el contrato API, evaluar la frontera de microservicio y ampliar pruebas y diagramas.

**Prompt relevante:** «avanza a la siguiente semana».

**Contenido aceptado o modificado:** se conservó el dominio de ocupación de Semanas 3 y 4; se agregó una frontera HTTP versionada y se decidió no extraer un microservicio sin métricas. El token estático se declara únicamente como mecanismo del prototipo local.
