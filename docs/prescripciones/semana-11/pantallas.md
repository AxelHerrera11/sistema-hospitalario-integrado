# Modelo de pantallas del prototipo

| Ancla | Pantalla conceptual | Propósito |
|---|---|---|
| `#inicio` | Inicio de flujo | Identificar paciente y comenzar |
| `#crear` | Crear | Revisar búsqueda y campos genéricos |
| `#advertencia` | Advertencia | Mostrar `mild` sin usar solo color |
| `#rechazo` | Rechazo | Comunicar 422 y que no hubo persistencia |
| `#detalle` | Detalle | Presentar estado y resumen |
| `#firma` | Confirmación | Mostrar una confirmación conceptual |

Los enlaces solo navegan entre anclas locales. No envían, guardan ni firman
datos. Los campos definitivos, permisos y contenido de firma están pendientes
del contrato aprobado.
