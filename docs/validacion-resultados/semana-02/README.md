## Resumen

Esta entrega define los requerimientos funcionales y no funcionales del flujo de revision clinica de resultados de laboratorio por un bioquimico. Tambien muestra como aplicar DIP para que los casos de uso de validacion dependan de contratos de dominio y no de detalles concretos de base de datos, notificacion o auditoria.
