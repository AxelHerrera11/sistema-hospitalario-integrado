# Declaración de uso de inteligencia artificial - Semana 4

**Herramienta:** Claude Code con el modelo Claude Opus 5.5 (`claude-opus-5-5`).

**Propósito:** extender el Micro-HIS de Semana 3 con el contrato Repository, el adaptador InMemory, la entrada MVC y sus pruebas; redactar la documentación y los diagramas, y ejecutar las validaciones.

**Contenido generado o modificado:** todo el código y la documentación de Semana 4 son borradores generados con IA. Durante el trabajo se corrigió un commit que se había creado con una verificación fallida (el comentario del contrato nombraba la tecnología de persistencia), se hizo portable una verificación que dependía de `GLOB_BRACE` y se reorganizó el diagrama del repositorio compartido porque era demasiado ancho.

**Validación:** las salidas de [EVIDENCIA.md](./EVIDENCIA.md) provienen de ejecuciones reales. La revisión humana de la estudiante y la aprobación requerida en `develop` quedan **pendientes**.
