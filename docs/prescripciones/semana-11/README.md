Estado: `PROPUESTO`. El prototipo es un artefacto estático para recorrer
pantallas; no llama a una API ni ejecuta reglas clínicas.

## Restricciones

- Todas las vistas son datos de ejemplo no clínicos.
- No se agrega endpoint, acción o pantalla para excepción de alergia.
- No se presenta el prototipo como producto integrado ni como evaluación con
  usuarios.
- El resultado 422 se muestra como no guardado; no hay camino de continuación
  que lo convierta en éxito.
